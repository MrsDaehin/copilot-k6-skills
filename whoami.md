# Who Am I

**Almudena "Almu" Vivanco**

Principal Performance Engineer, K6 and AI advocate, and international speaker focused on performance testing, observability, and intelligent systems.

With more than 20 years of experience building and testing large-scale distributed systems, Almu helps organizations adopt modern performance testing practices that leverage k6 and AI for efficient, data-driven validation.

## What I Believe In

- Performance testing as code, versioned like software
- Using AI to enhance test design and analysis
- Leveraging k6 and Grafana for observable, SLO-driven testing
- Automating performance suites into delivery pipelines

## What I Teach

- How to generate k6 test suites with k6 and AI
- How to drive k6 scenarios from AI-enhanced configurations
- How to automate k6 workflows with Prometheus remote write
- How to validate performance using automated assertions
- How to integrate k6 testing into delivery pipelines with Grafana

## In This Workshop

This repository and session are designed to show how modern cloud-native systems can be tested for performance using k6, with AI-assisted test generation and Grafana observability.

The goal is to help teams learn from AI-enhanced k6 tests, so they can build performant systems with confidence.
